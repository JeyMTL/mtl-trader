# MTL Trader – Product Brief

## Product summary

MTL Trader is a trading journal SaaS MVP designed for traders who want to import their trade history, review performance analytics, and manage plan-based usage limits.

## What it includes

- Trade import for CSV and Excel-style data
- Dashboard with performance overview
- Trading calendar and analytics views
- MT5 sync workflow
- Subscription, trial, and quota enforcement
- Payment and admin approval flows
- Mobile-ready Capacitor structure

## Stack

- Next.js
- React + TypeScript
- Supabase
- Vercel-ready deployment
- PayPal + bank-transfer billing integration

## Why it matters

This is a practical SaaS starter in a niche with clear user value. The product has the core layers needed for a real service:

- authentication
- trade data ingestion
- business rules
- billing logic
- admin workflow
- mobile-ready front end

## Suggested positioning

This should be sold as a working MVP, not a fully mature startup. It is most attractive to:

- founders building a trading analytics product
- developers seeking a SaaS starter with real business logic
- agencies or investors looking for a productized MVP in the trading niche
